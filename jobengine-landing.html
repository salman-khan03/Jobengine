The problem

Most job boards can't answer the only question that matters first.

For an F-1 student, "does this company sponsor H-1B?" decides whether an application is worth an hour or worth nothing. That data exists — the Department of Labor publishes every LCA filing — but no job board joins it against live listings. JobEngine does that join, locally, in one command.

✗ without jobengine

Apply → interview → final round → "unfortunately we can't sponsor at this time." Weeks lost per dead end, repeated across dozens of companies.

✓ with jobengine

jobengine search --sponsors-only filters every listing against real LCA filing history before you write a single cover letter.

What it does

One pipeline, fetch to offer.

jobengine fetch

35K+ listings, deduplicated. Pulls from multiple sources, collapses reposts and cross-posts into single canonical entries.

jobengine sponsors

H-1B LCA cross-referencing. Joins listings against Department of Labor LCA disclosure data to flag companies with real sponsorship history.

jobengine tailor

Honest resume tailoring. Reorders and selects your existing bullets per job description. Selection and reordering only — it never fabricates a claim, and a metric audit gate blocks unverifiable numbers.

jobengine track

Application tracking. Every application, stage, and follow-up in one local store — no spreadsheet drift.

jobengine serve

Zero-dependency HTTP API. A stdlib-only server exposes the whole engine to scripts and dashboards.

Principles

Built like it's going to be audited.

No fabricated metrics

The tailoring engine is architecturally unable to invent claims — an audit gate rejects any bullet with an unverifiable number.

Tested, gated, released

50 tests run on every push. Releases only publish when the suite is green and the tag matches the package version.

Fresh by default

A daily GitHub Actions pipeline refetches and dedups listings, committing only when the data actually changed.

Local first

Your applications, notes, and resume live on your machine. No account, no telemetry, no lock-in.
